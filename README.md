# Web Development Lab 01

This folder contains the HTML solutions for Web Technology Lab 01. The exercises demonstrate basic HTML document structure, headings, paragraphs, links, tables, navigation, lists, and forms.

## Requirements

- A modern web browser such as Chrome, Edge, or Firefox
- A text editor or IDE such as Visual Studio Code
- No package installation or build step is required

## Run the Portfolio

1. Open `WebLabStudentPortfolio/index.html` in a web browser.
2. Select **Open** beside any question to view that exercise.

The pages can also be opened directly from the `WebLabStudentPortfolio` folder.

## Exercises

| Question | File | Contents |
| --- | --- | --- |
| 1 | `Q1_Student_Profile.html` | Student profile, education, skills, projects, and university link |
| 2 | `Q2_CS_Department.html` | Computer Science department information, degree programs, courses, and faculty |
| 3 | `Q3_Food_Restaurant.html` | Restaurant navigation, menu, food preparation process, and contact details |
| 4 | `Q4_College_Homepage.html` | College overview, departments, admissions, programs, and contact information |
| 5 | `Q5_Hotel_Booking.html` | Hotel room booking form |
| 6 | `Q6_Job_Portal.html` | Job application form |
| 7 | `Q7_Real_Estate.html` | Real estate property listing form |
| 8 | `Q8_Event_Registration.html` | Music festival event registration form |
